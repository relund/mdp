# Gemini Project Context: MDP2

This project is the `MDP2` R package, designed for modeling and solving Markov Decision Processes (MDPs), semi-Markov decision processes (semi-MDPs), and hierarchical-MDPs (HMDPs) with discrete time-steps, states, and actions.

## Project Overview

- **Core Functionality:** Building, saving, loading, and solving MDPs under finite and infinite time-horizons.
- **Architecture:** The package follows a two-step workflow:
    1.  **Model Building:** Construct the MDP in R and save it as a set of binary files.
    2.  **Optimization:** Load the model from binary files into a C++ engine for efficient solving using algorithms like policy iteration and value iteration.
- **Technology Stack:**
    - **Frontend:** R (provides the user API and model construction tools).
    - **Backend:** C++ (using `Rcpp`) for performance-critical computations.
    - **Data Structure:** State-expanded directed hypergraph.
    - **Linear Algebra:** Uses LAPACK and BLAS for solving linear equations (e.g., in policy iteration).

## Key Directories

- `R/`: R function definitions, including the high-level API for MDP construction and solver invocation.
- `src/`: C++ source code. Contains the core `HMDP` class, solvers, and binary I/O logic.
- `inst/models/`: Example pre-built binary MDP models.
- `tests/testthat/`: Comprehensive test suite using the `testthat` framework.
- `vignettes/`: In-depth documentation and use-case examples.
- `man/`: R documentation files (generated by Roxygen2).

## Building and Running

Since this is a standard R package with compiled code, use the following commands:

- **Install Dependencies:**
  ```r
  install.packages(c("Rcpp", "dplyr", "diagram", "tibble", "testthat", "knitr", "rmarkdown"))
  ```
- **Build and Install:**
  ```bash
  R CMD INSTALL .
  # Or from within R:
  # devtools::install()
  ```
- **Run Tests:**
  ```bash
  R CMD check .
  # Or from within R:
  # devtools::test()
  ```
- **Generate Documentation:**
  ```r
  devtools::document()
  ```

## Development Conventions

- **R Documentation:** Use [Roxygen2](https://roxygen2.r-lib.org/) comments in `R/` files.
- **C++ Integration:** The project heavily relies on [Rcpp Modules](https://cran.r-project.org/web/packages/Rcpp/vignettes/Rcpp-modules.pdf) to expose the `HMDP` class to R.
- **Binary Format:** The project uses a custom binary format for storing MDPs, consisting of several files (e.g., `stateIdx.bin`, `actionIdx.bin`, `transProb.bin`). Refer to `src/hmdp.h` (under `HMDPReader` class documentation) for the detailed specification of this format.
- **Testing:** All new features or bug fixes should include corresponding tests in `tests/testthat/`.

## Key Files for Reference

- `DESCRIPTION`: Package metadata and dependencies.
- `NAMESPACE`: Defines exported R functions and imported packages/modules.
- `src/hmdp.h`: The primary C++ header defining the `HMDP` class and its algorithms.
- `src/modules.cpp`: Defines the `Rcpp` module interface between R and C++.
- `R/binary.R`: R functions for handling the binary model files.
- `R/mdp.R`: Main R API for interacting with MDPs.
