# Save the MDP to binary files

Currently do not save external files.

## Usage

``` r
save_mdp(mdp, prefix = "", get_log = TRUE)
```

## Arguments

- mdp:

  The MDP loaded using
  [`load_mdp()`](http://relund.github.io/mdp/reference/load_mdp.md).

- prefix:

  A character string with the prefix added to `bin_names`. Used to
  identify a specific model.

- get_log:

  Output the log as a message.
